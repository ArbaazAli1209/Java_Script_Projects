# 🐍 JavaScript Snake Game

A classic **Snake Game** built using **HTML, CSS, and Vanilla JavaScript**. The game is fully responsive and works on both desktop and mobile devices with keyboard and touch controls.

## 🎮 Demo

```
https://snake-game-neon-theta-39.vercel.app/
```

---

## ✨ Features

- 🎯 Classic Snake gameplay
- 📈 Real-time score tracking
- 🏆 High score saved using Local Storage
- ⏱️ In-game timer
- 🎮 Keyboard controls for desktop
- 📱 Touch controls for mobile devices
- 📱 Responsive design
- 🍎 Random food generation
- 🚫 Wall collision detection
- 🔄 Restart game functionality
- 🎉 Start Game & Game Over modals

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)

---

Simply open the project folder and launch **index.html** in your preferred browser.

## 🎮 Controls

### Desktop

| Key | Action |
|------|--------|
| ⬆️ | Move Up |
| ⬇️ | Move Down |
| ⬅️ | Move Left |
| ➡️ | Move Right |

### Mobile

Use the on-screen directional buttons to control the snake.

---

## 🧠 Game Rules

- Eat the red food to grow the snake.
- Each food increases your score.
- Avoid hitting the walls.
- Your highest score is automatically saved in your browser.
- Try to beat your personal best!
